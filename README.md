# godot-zatacka

My take on the classic Zatacka game, created in Godot. I chose this game because
* the rules are simple
* it holds a sentimental value - we used to play it a lot before classes at uni 😁

## About this project

This is my very first Godot project (and my first ever game!) and serves as a learning ground for me to learn Godot (and game development in general).

## About Zatacka

A classic arcade multiplayer game, which itself is a remake of [Achtung, die Kurve!](https://en.wikipedia.org/wiki/Achtung,_die_Kurve!). The player controls a snake which moves around the screen leaving a trail, and needs to avoid obstacles. The goal is to survive longer than all opponents without crashing into walls or other snakes. Up to 6 players, all using the same keyboard 😆.
